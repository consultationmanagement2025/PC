```

└─ Fill form with consultation details
└─ Click Create Consultation
└─ Consultation appears immediately ✅

Step 2: Share Link with Citizens
└─ Public URL: public-consultations.php
└─ Announce in newsletter/social media
└─ Embed on website
└─ Citizens can access immediately ✅

Step 3: Citizens Submit Feedback
└─ Visit public portal
└─ Browse consultations
└─ Click Submit Feedback
└─ Fill feedback form
└─ Submit (status: pending approval) ✅

Step 4: Admin Reviews Feedback
└─ Dashboard shows pending count
└─ Review each feedback item
└─ Approve or reject
└─ Approved feedback shows publicly ✅

Step 5: Monitor Engagement
└─ View real-time statistics
└─ Track contributor count
└─ See feedback categories
└─ Close consultation when done ✅
```
