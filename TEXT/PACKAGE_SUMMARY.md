```
CITIZEN EXPERIENCE
═══════════════════════════════════════════════════════════════════

1. DISCOVER
   Visit public-consultations.php
           │
           ▼
   See all active consultations
           │
           ▼

2. PARTICIPATE
   Search/filter consultations
           │
           ▼
   Click "Submit Feedback"
           │
           ▼
   Login (if not already)
           │
           ▼
   Fill feedback form
           │
           ▼
   Submit feedback
           │
           ▼

3. WAIT FOR APPROVAL
   Feedback status: PENDING
           │
           ▼
   Admin reviews (usually 24-48 hours)
           │
           ▼

4. SEE RESULT
   Approved: Feedback appears publicly ✅
   Rejected: Not shown (admin decision)
           │
           ▼


ADMIN EXPERIENCE
═══════════════════════════════════════════════════════════════════

1. CREATE
   Fill consultation form
           │
           ▼
   Click Create
           │
           ▼
   Consultation goes LIVE immediately ✅
           │
           ▼

2. MONITOR
   Dashboard shows stats
           │
           ▼
   Real-time feedback notifications
           │
           ▼

3. MANAGE
   Review pending feedback
           │
           ├─ APPROVE → appears publicly
           │
           ├─ REJECT → hidden
           │
           └─ REVIEW → wait

4. CLOSE
   When deadline reached
           │
           ▼
   Click Close
           │
           ▼
   Consultation status: CLOSED
           │
           ▼
   New feedback blocked
   Old feedback still visible
```
